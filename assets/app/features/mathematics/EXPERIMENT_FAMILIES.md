# 数学实验室：实验族与内容组织

## 目标

数学实验室专注于 **Cocos 2D 能够完整表达的平面几何**，不扩展为整数、概率、统计或高维数学百科。它不采用“一种定理对应一张目录卡片”的结构；顶层目录只展示少量稳定的**几何实验族**，每个实验族复用同一套平面舞台、几何对象和交互语义，并通过带名称、刻度与预览的离散滑轨切换同类内容。

选题覆盖小学至高中几何，但不以教材章节为中心，而以“简单作图条件产生难以预判的关系”为标准。内容应允许用户直接拖动点、边、圆、切线或轨迹，同时持续揭示共线、共圆、相切、等距、等角、面积保持、包络或极值等性质；仅显示完成后的图形或证明步骤，不构成独立实验。

## 信息层级

```text
Mathematics Lab
└── Experiment Family（目录卡片）
    ├── Phenomenon Track（离散内容滑轨）
    ├── Stage（该实验族持续存在的共享舞台）
    ├── Parameters（当前几何构型的连续参数）
    ├── Motion Loop（持续运动的相位与速度）
    └── Observation / Compare（单层观察或叠加比较）
```

内容滑轨、参数滑块和运动控制必须具有不同的视觉语义：

- **内容滑轨**切换同类现象，使用命名刻度和吸附位置，不显示成无含义的连续数值。
- **参数滑块**只调整角度、长度比、半径、速度、轨迹采样等连续或枚举参数。
- **运动控制**只调整速度、慢放或用户主动暂停；默认状态始终运动，不承担内容导航。
- 切换现象时尽量保留共享对象与用户输入，通过连续变形揭示同一数学世界中的不同结构，避免销毁整个页面后加载另一张卡片。

## 持续动画约束

数学实验不是完成一次构造后停住的解题演示，而是由几何规律驱动的动态展品。进入实验时舞台已经运动，并在用户离开前持续演化：

- 每个实验必须声明稳定的运动驱动量，例如沿圆周移动的点、连续变化的角度、滚动圆相位或周期振子的相位。
- 周期系统采用无缝循环；非周期但有界的系统持续积分；一次性构造只有在能够通过多对象错相、连续发射或画面外回收形成自然循环时才可采用。
- 模型不得因为到达终点、完成一次作图或播放完预设动画而停住；暂停只能由用户主动触发。
- 内容或参数切换优先保持当前相位并连续过渡，不用频繁硬重置破坏观赏性。
- 轨迹、残影、包络和辅助线随运动生成并受控衰减，使画面同时呈现“当前状态”和“运动留下的结构”。
- 任何循环都必须保持几何关系正确；不能为了无缝播放而让对象瞬移、穿帮或违反当前构型约束。

## 建议的顶层实验族

顶层长期保持六至八项。首版采用以下六项：

| 几何实验族 | 族内内容滑轨 | 共享结构 |
| --- | --- | --- |
| 三角形隐藏结构 | 欧拉线、九点圆、拿破仑定理、莫雷定理、西姆松线 | 同一个可拖动三角形、圆、中心、投影点与辅助线 |
| 圆、切线与圆幂 | 弦角关系、切割线、点幂、根轴、阿波罗尼斯圆、Steiner 圆链 | 圆、弦、切线、交点、幂值与相切约束 |
| 圆锥曲线与轨迹 | 椭圆、抛物线、双曲线、焦点反射、轨迹定义、Poncelet 闭合 | 焦点、准线、切线、反射线、距离和与运动点 |
| 几何变换 | 轴对称、旋转、平移、位似、圆反演、连续复合变换 | 原图与像、变换中心、对应点、角度和距离比例 |
| 运动生成曲线 | 摆线、内外摆线、旋轮线、Lissajous、直线包络 | 平移与旋转、轨迹点、频率比、半径比与闭合条件 |
| 作图、约束与极值 | 尺规作图、最短路径、定长连杆轨迹、等距点集、面积与周长极值 | 可拖动约束、候选构型、误差、长度和面积测量 |

现有 `lissajous/` 是“运动生成曲线”的首个内容实现；后续目录不应继续把它作为与实验族平级的永久产品概念。代码迁移可以分阶段进行，先保留现有模块入口，再引入几何实验族容器和变体定义。

## 收纳规则

新内容只有满足以下条件，才收入现有实验族：

1. 与族内内容共享主要舞台、对象模型和交互动作；
2. 切换后能够保留部分用户状态，并通过连续变化帮助比较；
3. 用户能够识别哪些点和尺寸发生变化，哪些几何关系保持不变；
4. 它提供新的认知结果，而不只是换一组预设参数或视觉皮肤。

无法复用交互语义的内容不应为了减少目录数量而强行合并；只有当它能够支撑多个同类现象和独立视觉世界时，才新增顶层实验族。

## 实现边界

- 顶层目录的数据模型面向 `GeometryExperimentFamily`，而不是单个定理或图形。
- 每个实验族声明自己的 `variants`、共享状态、变体参数和状态迁移规则。
- 离散内容滑轨切换 `variantId`；连续参数由当前变体独立声明，避免一个巨型通用控制面板。
- 同一实验族共享二维舞台渲染器时，模型层仍保持几何构造、约束求解与绘制逻辑分离，便于验证不变量和数值正确性。
- 目录卡片只表达实验族的核心问题与视觉世界，不在卡片上罗列全部变体。

## 验收标准

一个实验族完成时，应满足：目录中只占一个入口；族内变体可以通过命名滑轨发现；进入后无需操作即可持续运动；除用户主动暂停外不存在终止状态；循环没有可见跳变；切换过程保持舞台与运动相位连续；参数、内容导航和运动控制不会混淆；每个变体都明确展示输入、变化量、不变量与反直觉结果；新增同类变体不需要复制完整页面结构。
